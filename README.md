# AI Brand Generator

An AI-powered web application designed to help founders, creators, and businesses instantly generate brand identities—from brand names and taglines to full visual themes and messaging strategies.
---

## Features

* **AI Copy & Asset Generation:** Instantly generate taglines, brand descriptions, and promotional ideas powered by Google Gemini AI.
* **Full-Stack Architecture:** Powered by a Node.js/Express backend and a modern React frontend.
* **Live Web Preview:** Optimized frontend setup ready for deployment on GitHub Pages.
* **Developer Friendly:** Simple setup using standard NPM scripts.

---

## Tech Stack

* **Frontend:** React.js, Vite / Create React App, HTML5, CSS3 / Tailwind
* **Backend:** Node.js, Express.js
* **AI Integration:** Google Cloud / Gemini API
* **Deployment:** GitHub Pages (Frontend)

---
